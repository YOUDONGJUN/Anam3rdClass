# 지도 바로가기, 모임 1시간 전 알림, 밤에는 조용히

- 날짜: 2026-11-26
- 상태: 완료
- PR: #10

## 배경 (어떤 문제였나)

#9를 머지한 뒤 "사용자 편의성 쪽으로 더 있으면 좋을 기능"을 다시 살폈다. 그중 작업은 작은데 바로 느껴지는 세 가지를 먼저 한다.

1. **장소를 찾아가기 번거롭다.** 장소가 글자로만 보여서, 지도 앱을 열고 장소 이름을 다시 쳐야 했다.
2. **성사된 3교시를 잊는다.** 성사 알림은 며칠 전에 올 수도 있다. 모이기 직전에 다시 알려 주는 알림이 없었다. 캘린더 파일의 1시간 전 알림은 캘린더에 넣은 사람만 받는다.
3. **새 3교시 알림이 밤에도 온다.** #9에서 우리 학교 새 3교시 알림을 기본으로 켰다. 그래서 새벽에 3교시를 열면 학교 원우 모두의 폰이 울린다.

## 정한 것

### 1. 지도 바로가기
- 3교시 상세의 장소 옆에 **[카카오맵] [네이버지도]** 를 둔다. 누르면 장소 글자로 지도 검색이 열린다.
- API 키가 필요 없다. 우리 서버는 아무것도 보내지 않는다. 누른 사람의 브라우저가 지도 사이트를 연다.

### 2. 모임 1시간 전 알림 (`REMINDER`)
- **받는 사람:** 성사된 3교시의 참여자 모두. 연 사람도 받는다.
  - 성사 = 취소되지 않았고, 인원이 최소 인원 이상. 최소 인원이 없으면 2명 이상.
- **언제:** 모임 1시간 전에 한 번. 내용은 "1시간 뒤 3교시예요 · 21:00 · 장소"이고, 누르면 상세로 간다.
- **안 보내는 경우:**
  - 모임 시간을 바꾸면 새 시간 1시간 전에 다시 보낸다.
  - 모임 2시간 안쪽에 연 3교시는 보내지 않는다. 방금 모였기 때문이다.
  - 서버가 늦게 깨서 모임까지 10분 이하 남았으면 보내지 않는다. 이미 이동 중이다.
  - 1시간 전에 아직 성사 전이면 보내지 않는다. 마감 알림과 성사 알림이 따로 있다.
- 내 정보 › 알림에서 끌 수 있다.

### 3. 밤에는 조용히
- **다 같이 받는 알림**(새 우리 학교 3교시, 새 연합 3교시, 새 공지)은 **밤 12시~아침 8시**(한국 시간)에 보내지 않는다. 대신 **아침 8시에** 보낸다.
- **아침에 보낼 때:**
  - 이미 마감됐거나 취소됐거나 꽉 찬 3교시는 건너뛴다.
  - 지운 공지는 보내지 않는다.
- **내 3교시 알림**(참여·나감, 성사, 마감, 시간 변경·취소, 빈자리, 1시간 전)은 밤에도 보낸다. 3교시는 밤에 모이기 때문이다.
- 알림 설정 화면에 위 규칙을 한 줄로 적는다.

## 버린 대안과 이유

| 대안 | 버린 이유 |
|---|---|
| 상세에 지도 미리보기 넣기 | 카카오 지도 API 키와 도메인 등록이 필요하다. 장소가 자유 글자라 좌표도 없다. 카카오 장소 검색은 #9에서 이미 "나중에"로 정했다 |
| 1시간 전 대신 30분 전 | 이동 시간이 모자라다 |
| 원우가 알림 시간을 고르기 | 설정만 늘어난다. 다른 시간이 필요한 원우는 캘린더 파일 알림을 쓰면 된다 |
| 성사 전 3교시에도 1시간 전 알림 | 마감 30분 전 알림이 이미 있다. 무산될 수 있는 모임을 "곧 모여요"라고 알리면 헷갈린다 |
| 밤에 연 3교시 알림은 그냥 버리기 | 다음 날 저녁 3교시를 새벽에 열면 아무도 모르고 지나간다 |
| 모든 알림을 밤에 끄기 | 밤 11시 3교시의 성사·빈자리·1시간 전 알림은 그 시간에 와야 쓸모가 있다 |
| 원우가 조용한 시간을 고르기 | 설정만 늘어난다. 필요해지면 그때 만든다 |
| 아침 8시에 밤사이 3교시를 한 알림으로 묶기 | 밤에 3교시가 여러 개 열리는 일이 드물다. 묶으면 대상(학교·기수·연합)이 달라 계산만 복잡해진다 |

## 결과

- **백엔드**
  - DB: `V14__meet_reminder_quiet_hours.sql`. 3교시에 `meet_reminded_at`과 `announce_pending`, 공지에 `announce_pending`을 더했다.
  - 알림 종류에 `REMINDER`를 더했다. 밤 시간 판단은 `QuietHours`가 한다.
  - `DeadlineReminderJob`을 `ReminderJob`으로 바꿨다. 1분마다 세 가지를 본다: 마감 30분 전, 모임 1시간 전, 밤사이 미룬 알림.
- **프론트**
  - 3교시 상세 장소 옆에 [카카오맵]과 [네이버지도]를 넣었다.
  - 알림 설정에 "모임 1시간 전" 항목과 밤 규칙 안내 한 줄을 넣었다.
- **테스트**
  - 백엔드 188개(새로 6개), 프론트 lint, 단위 테스트 76개, 빌드가 모두 통과했다.
  - 화면: 390px과 1440px, 다크 모드에서 겹침이나 가로 넘침이 없다. 긴 장소 이름도 줄바꿈된다.
  - Postgres 17: V14가 적용됐다. 아래 세 가지를 실제 서버로 확인했다.
    - 한국 시간 07시에 연 3교시와 공지는 알림이 미뤄졌다.
    - 시계를 08시로 넘기자 미룬 알림이 나갔다.
    - 1시간 전 알림이 나갔다.

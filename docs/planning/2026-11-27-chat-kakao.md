# 톡방을 카톡처럼: 키보드 · 맨 아래로 · 답장 · 공감 · 톡방 공지

- 날짜: 2026-11-27
- 상태: 완료
- PR: #30
- 앱: v1.3.0 (아이폰 키보드 위 막대를 숨기려면 앱을 새로 깔아야 한다)

## 배경 (어떤 문제였나)

아이폰(18 Pro Max)으로 써 본 의견:

- 입력창을 누르면 톡방이 맨 아래가 아니라 **중간**을 보여 준다.
- 이모티콘을 두 번 눌러도 안 보내진다 (카톡은 고른 것을 한 번 더 누르면 바로 간다).
- 톡방을 눌러도 키보드 · 이모티콘함이 내려가지 않는다.
- 키보드 위에 ∧ ∨ 완료 막대가 뜨고, 입력창과 키보드 사이에 **흰 빈칸**이 있다.
- 위로 올려 보다가 맨 아래로 한 번에 돌아갈 단추가 없다.

"카톡을 벤치마킹한다고 생각하고" 답장 · 공감 · 톡방 공지 같은 것도 같이 넣기로 했다.

## 원인

- **중간으로 감**: 키보드가 올라오면 보이는 높이(visualViewport)에 맞춰 톡방이 줄어드는데, 스크롤 위치(scrollTop)는 그대로라
  줄어든 만큼 아래가 가려졌다.
- **흰 빈칸**: 입력창 아래에 홈 표시줄 자리(`env(safe-area-inset-bottom)`, 아이폰 34px)를 늘 비워 뒀다. 키보드가 올라와도 그대로였다.
- **∧ ∨ 완료 막대**: 아이폰 웹뷰가 붙이는 막대라 웹으로는 못 없앤다 → 앱 플러그인(`@capacitor/keyboard`)이 필요하다.

## 정한 것

### 키보드 · 스크롤
- 톡방이 "맨 아래까지 남은 거리"를 기억하고, 높이가 바뀌면(키보드 · 이모티콘함 · 답장 줄 · 사진 고르기) 그 거리를 지킨다.
  맨 아래를 보고 있었으면 최신 메시지가 그대로, 위를 보고 있었으면 **보던 줄이 그대로** 보인다 (ResizeObserver).
- 폰에서 키보드 · 이모티콘함이 열린 채 톡방을 누르면 **내리기만** 한다 (첫 터치로 사진이 열리거나 메뉴가 뜨지 않게).
- 입력창을 잡고 있는 동안은 아래 여백(홈 표시줄 자리)을 없애 입력창이 키보드에 바로 붙는다.
- 아이폰 앱: **톡방에서만** 키보드 위 막대를 숨기고(`setAccessoryBarVisible(false)`, 나가면 다시 보임),
  키보드가 올라오면 앱 화면을 키보드 위까지만 줄인다(`resize: native`).

### 맨 아래로 · 새 메시지 띠
- 맨 아래에서 300px 넘게 올라가 있으면 오른쪽 아래에 ↓ 단추.
- 위로 올려 둔 동안 원우 메시지가 오면 아래에 **"보낸 사람 첫 줄" 띠** (여러 개면 개수). 누르면 맨 아래로.

### 이모티콘
- 이모티콘함에서 처음 누르면 미리 보기, **같은 것을 한 번 더 누르면(두 번 터치) 바로 보낸다.** 미리 보기를 눌러도 보낸다.
- 빠르게 두 번 눌러도 폰이 화면 확대로 받아들이지 않게 `touch-action: manipulation`.
- 이모티콘함 맨 위에 **최근 쓴 이모티콘** 한 줄(4개, 이 기기에만 저장).

### 길게 눌러 메뉴
- 폰: 메시지를 **길게 누르면** 메뉴 (짧게 누르면 아무것도 안 함 — 카톡처럼). PC: 누르거나 오른쪽 클릭.
- 메뉴: 공감 6개 · 답장 · 복사 · 톡방 공지로 올리기(연 사람) · 지우기(내 것) · 신고·차단(원우 것).
  메뉴가 열릴 때 브라우저가 첫 단추(❤️)를 잡아 이미 누른 것처럼 테두리가 생기지 않게, 맨 위 메시지 줄을 잡는다.
- 길게 누른 손을 떼는 순간 그 자리의 click 이 메뉴 바깥(닫기)이나 메뉴 항목(지우기 등)을 누른 것이 되지 않게,
  **메뉴 안에서 새로 누른 것만** 받는다.

### 보내는 중 · 다시 보내기
- 보내면 서버 답을 기다리지 않고 바로 흐린 말풍선("보내는 중")이 뜨고 입력창이 비워진다. 여러 개를 빨리 보내도 보낸 순서대로 간다.
- 실패하면 말풍선 옆 ! 와 **다시 보내기 · 보내지 않기**.
  인터넷 문제는 알림을 겹쳐 띄우지 않고, 서버가 이유를 알려 준 것(너무 빨리 보냄 · 오늘 사진을 다 보냄)만 알림으로도 띄운다.

### 답장 (서버)
- 메시지에 `reply_to_id` (`V26`). 원래 메시지는 이 톡방의, 지우지 않은 원우 메시지만.
- 말풍선 위에 "○○에게 답장 / 원래 메시지 한 줄". 누르면 원래 메시지로 가서 잠깐 테두리.
  화면에 없는 오래된 메시지면 **이전 메시지를 더 불러와서** 찾아간다 (50개씩 20번까지).
- 원래 메시지를 지우면 "지운 메시지예요". 이름은 3교시 공개 규칙(성사 전 가려진 이름)을 따른다.

### 공감 (서버)
- 하트 · 좋아요 · 확인 · 웃겨요 · 놀라워요 · 슬퍼요 (카톡과 같은 6가지). 메시지마다 **한 사람이 하나**, 다른 것을 누르면 바뀌고 같은 것을 누르면 빠진다.
- 메시지 아래에 "❤️ 2 · 👍 1". 누른 사람이 **누구인지는 보이지 않는다** (가려진 이름 규칙과 부딪히지 않게).
- 화면에 먼저 바꾸고 서버 답으로 맞춘다. 다른 원우가 누르면 실시간 신호(`chat-change`)로 그 메시지만 다시 읽는다.
- 폰 알림은 보내지 않는다 (카톡처럼).

### 톡방 공지 (서버)
- **연 사람**이 메시지 하나를 톡방 위에 올린다 (장소 · 시간 안내). 톡방마다 하나, 새로 올리면 앞의 것은 내려간다. 메시지에 `pinned_at`.
- 위 줄을 누르면 그 메시지로. 연 사람은 "내리기", 누구나 "접기"(이 기기에만, 새 공지가 오면 다시 펴짐). 접으면 머리에 📢 단추.
- 공지 메시지를 지우면 공지도 내려간다. 취소된 3교시는 올릴 수 없다.

## 버린 대안과 이유

| 대안 | 버린 이유 |
|---|---|
| 입력창을 누르면 무조건 맨 아래로 | 위에서 읽던 사람이 자리를 잃는다. 카톡도 보던 줄을 지킨다 |
| 웹으로 ∧ ∨ 막대 숨기기 | 웹뷰가 붙이는 막대라 웹에서는 방법이 없다 |
| 앱 전체에서 ∧ ∨ 막대 숨기기 | 가입 · 3교시 만들기 같은 화면에서는 "완료"가 키보드를 내리는 단추다. 아이폰은 빈 곳을 눌러도 키보드가 안 내려가서 갇힌다 |
| 두 번 터치를 "0.3초 안에 두 번"으로 | 고른 뒤 잠깐 보고 다시 누르는 사람도 보내져야 한다. "고른 것을 다시 누르면 보냄"이면 둘 다 된다 |
| 짧게 눌러 메뉴 (예전 방식) | 사진 · 이모티콘을 누르다가 메뉴가 자꾸 뜬다. 카톡은 길게 누른다 |
| 공감에 누른 사람 이름 보이기 | 성사 전에는 이름이 가려지는 규칙과 부딪히고, 목록 화면이 하나 더 필요하다 |
| 공감 알림 보내기 | 폰이 너무 자주 울린다 |
| 공지를 별도 표(테이블)로 | 톡방마다 하나라 메시지에 시각(`pinned_at`)만 두면 된다 |
| 실패한 메시지를 자동으로 다시 보내기 | 같은 글이 두 번 갈 수 있다. 사람이 "다시 보내기"를 누르게 한다 |

- 서버: `ChatApiTest` (답장 · 공감 · 공지 시험 3개 추가).
- 화면: Chromium(안드로이드 엔진, 폰 흉내)과 WebKit(아이폰 엔진)에서 360 · 390 · 430px로 키보드(화면 줄임) · 맨 아래로 · 새 메시지 띠 ·
  톡방 눌러 내리기 · 이모티콘 두 번 터치 · 최근 · 보내는 중/실패/다시 보내기 · 길게 눌러 메뉴 · 복사 · 공감(실시간) · 답장(오래된 메시지 찾아가기) ·
  공지 올리기/접기/내리기 · 지우기를 눌러 봤다. PC(마우스)와 다크 모드 모습도 봤다.

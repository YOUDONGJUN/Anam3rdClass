# 기획 히스토리

안암3교시를 만들면서 **무엇을 왜 그렇게 정했는지** 남기는 곳이에요.
코드와 커밋에는 "무엇을"만 남고 "왜"는 사라져서, 기획 한 건마다 파일 하나로 적어 둡니다.

## 쓰는 법

1. 기획을 시작하면 `YYYY-MM-DD-주제.md` 파일을 만들어요 (아래 틀 그대로).
2. 정한 것, **버린 대안과 버린 이유**까지 적어요. 나중에 "왜 이렇게 안 했지?"에 답하는 부분이에요.
3. PR 을 올리면 PR 본문의 "기획 문서" 칸에 이 파일 링크를 넣어요.
4. PR 이 머지되면 파일의 `결과`에 PR 번호를 적고, 아래 표의 상태를 바꿔요.

```markdown
# 제목

- 날짜: YYYY-MM-DD
- 상태: 기획 중 | 개발 중 | 완료 | 보류
- PR: #번호

## 배경 (어떤 문제였나)
## 정한 것
## 버린 대안과 이유
## 결과
```

- 상태: 완료

## 배경 (어떤 문제였나)
"번개"라는 말과 학번 표시가 대학원 분위기와 맞지 않았고, 한 모임에 마실 것을 하나만 고를 수 있었다.

## 정한 것
- 화면의 "번개" → "3교시", "운영자" → "관리자"
- 학번 대신 기수(61기)와 학과(소보·빅융·인융). 표시는 `김*수 · 61기 · 인융`
- 마실 것 여러 개 (아무거나는 단독), 모임 목적 태그 3개까지
- 최소 인원 없음(열자마자 확정)과 최대 인원 없음을 따로
- 관리자는 어디서나 실명 + "관리자" 표시

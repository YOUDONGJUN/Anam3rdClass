## 배경 (어떤 문제였나)
특수대학원 동기·선후배끼리 "수업 끝나고 한잔?"을 먼저 꺼내기 민망하고, 사람을 모으기도 어렵다.

## 정한 것
- 성사 전에는 이름을 가린다 (김*수). 성사되면 참여자끼리만 실명과 오픈채팅을 공개한다
- 최소 인원이 안 모이면 조용히 무산 (누가 안 왔는지 드러나지 않게)
- 공지: 누구나 쓰고, 운영자 글은 표시, 운영자만 상단 고정
- 운영자 화면: 회원 차단·해제, 입장 코드, 통계
- 무료 배포: 화면+API 한 컨테이너 (Render), DB 는 Neon PostgreSQL
- 상태(모집 중·성사·무산)는 DB 에 저장하지 않고 지금 시각과 인원으로 계산 (무료 서버가 잠들어도 맞게)

# 톡방 이모티콘 · 읽음 숫자 · 들어옴/나감, 사진 확대·저장

- 날짜: 2026-11-27
- 상태: 완료
- PR: #28

## 배경 (어떤 문제였나)

- 톡방에서 메시지를 하나 보낼 때마다 폰 키보드가 내려갔다가 다시 올라왔다.
- "이모티콘은 없냐"는 요청. 폰 키보드의 이모지가 아니라 **카카오톡 같은 캐릭터 이모티콘**을 원했다.
- 내가 보낸 메시지를 누가 읽었는지 알 수 없었다 (카톡의 숫자 1).
- 누가 톡방에 들어오고 나갔는지 알 수 없었다.
- 추억·톡방 사진을 폰에서 손가락으로 확대할 수 없었고, 앱에서는 저장 버튼이 동작하지 않았다.

## 정한 것

### 키보드
- 보내기 단추를 눌러도 입력창에서 포커스가 빠지지 않게 한다 (`mousedown` 기본 동작 막기). 키보드가 계속 떠 있다.

### KU 호랑이 이모티콘 (12종)
- 우리가 직접 그린 캐릭터: KU 크림슨 후드를 입은 호랑이. KU 표기는 학교 허락을 받았다.
- 3교시에서 자주 쓰는 말 12개: 가는 중 · 어디야? · 고마워요 · 도착! · 늦어요 · 건배! · 수고했어요 · ㅋㅋㅋ · 미안해요 · 좋아요 · 또 봐요 · 배고파.
- 그림은 SVG 파일(`frontend/public/stickers/tiger/`)로 화면이 가진다. 글자는 도형으로 바꿔서 폰트 없이 어디서나 똑같이 보인다.
  살짝 움직이고, 폰의 '동작 줄이기'를 켜면 멈춘다. 서버는 하루 동안 캐시하게 한다.
- 입력창 **안 오른쪽**의 😊 단추 → 키보드 자리에 패널. 누르면 바로 보낸다 (쓰던 글은 그대로). 단추는 ⌨로 바뀌고, 누르면 다시 키보드.
- 톡방에는 말풍선 없이 크게. 메시지에는 이모티콘 이름(`tiger-going` 등)만 저장하고, 서버가 정해진 12개인지 검사한다. 글·사진과 같이 보낼 수 없다.
- 알림 · 톡방 목록 · 신고 기록에는 "(이모티콘) 가는 중"으로 보인다.

### 들어옴 · 나감
- 참여하면 "○○님이 들어왔어요", 나가거나 내보내지거나 탈퇴하면 "○○님이 나갔어요" 줄이 톡방 가운데에 남는다.
  **내보낸 것은 드러내지 않는다** (망신 주지 않게).
- 이름은 3교시 공개 규칙을 그대로 따른다 — 성사 전에는 가려진 이름.
- 안내 줄은 폰 알림을 보내지 않고, 안 읽은 수에 세지 않고, 지우거나 신고할 수 없다.
- 메시지 테이블에 `kind`(TEXT · JOIN · LEAVE)를 더했다 (`V25`).

### 읽음 숫자
- 메시지마다 아직 안 읽은 원우 수를 시각 옆에 띄우고, 누가 읽으면 실시간으로 줄인다.
- 서버는 "나 말고 원우들이 각자 마지막으로 읽은 메시지 번호" 목록만 준다. **누구인지는 주지 않는다.**
- 보낸 사람은 보낸 순간, **새로 들어온 사람은 들어온 순간까지 읽은 것으로** 친다 (카톡처럼). 그래서 참여 시각을 화면에 줄 필요가 없다.
- 읽은 자리가 실제로 바뀔 때만 톡방 원우에게 실시간 신호(`chat-reads`)를 보낸다. 1분마다 오는 '보고 있어요'는 빼서 신호가 넘치지 않게 한다.

### 사진 확대 · 저장
- 크게 보기 화면: 두 손가락 확대(최대 4배), 두 번 탭 확대/원래대로, 확대한 채로 끌어서 옮기기. 옆으로 넘기기는 확대하지 않았을 때만. PC는 휠 · 더블클릭.
- 저장 단추에 "저장" 글자를 붙였다.
  - 안드로이드 앱: 갤러리(사진/안암3교시)에 바로 저장. 안드로이드 9 이하는 저장 권한을 묻는다.
  - 아이폰 앱: 공유 창 → "이미지 저장" (`@capacitor/filesystem`으로 임시 파일을 만들어 공유).
  - 폰 브라우저: 공유 창 · PC: 내려받기.
  - 예전 앱(이 기능이 없는 빌드)이면 "앱을 업데이트하면 저장할 수 있어요"라고 알린다. **앱 기능이라 앱을 새로 빌드해 올려야 한다.**

## 버린 대안과 이유

| 대안 | 버린 이유 |
|---|---|
| 카카오톡 이모티콘 그대로 | 카카오와 작가의 저작물이라 쓸 수 없다 |
| Google Noto 움직이는 이모지 | 무료(CC BY 4.0)지만 폰 키보드의 기본 이모지와 같아서 "카톡 같은 이모티콘"이 아니다 |
| GIPHY 스티커 검색 | 해외 감성에 영어 위주, 부적절한 그림을 걸러야 하고 검색어가 외부로 나간다 |
| 이모지 글자를 보내고 화면에서 그림으로 바꾸기 | 서버를 안 고쳐도 되지만 캐릭터 이모티콘에는 맞는 글자가 없다 |
| 이모티콘을 PNG/WebP로 | 크기가 커지고 움직임을 넣기 어렵다. SVG는 12개에 약 200KB |
| 읽음 숫자: 원우별 참여 시각을 함께 보내 화면이 거르기 | 참여 시각과 "들어왔어요" 줄을 맞춰 보면 누가 어디까지 읽었는지 알 수 있다 |
| 읽음 숫자를 서버가 메시지마다 세서 보내기 | 누가 읽을 때마다 보이는 메시지 전부를 다시 보내야 한다 |
| 아이폰 저장도 앱 전용 코드(Swift)로 | Mac 없이 빌드해 시험할 수 없다. 공식 플러그인 + 공유 창으로 충분하다 |
| 내보내면 "○○님을 내보냈어요" | 내보내진 원우가 망신당한다. 연 사람도 부담스럽다 |

## 나중에 고친 것 (2026-11-27, #29)

- **아이폰에서 입력창을 누르면 화면 전체가 확대되던 문제**: 아이폰(앱·사파리)은 글자가 16px 보다 작은 입력칸을 누르면 확대한다.
  톡방 입력창과 3교시 검색칸이 15px 였다 → 16px. 앞으로 생길 입력칸도 16px 아래면 테스트(`src/inputs.test.ts`)가 실패한다.
  - 버린 대안: 화면 설정에 `maximum-scale=1` — 확대는 막지만 안드로이드 브라우저에서 손가락 확대까지 막힌다.
  - 버린 대안: CSS 로 모든 입력칸을 16px 이상으로 강제 — 일부러 크게 만든 입력칸(정산 금액 · 인증코드)까지 16px 로 줄어든다.
- **이모티콘은 보내기를 눌러야 보낸다 (카톡처럼)**: 패널에서 고르면 입력창 위에 미리 보이고(✕ 로 빼기), 보내기 단추로 보낸다.
  글도 써 두었으면 이모티콘 → 글 순서로 두 개를 보낸다 (이모티콘은 글과 한 메시지에 담지 않는다).
- **앱 버전 관리 시작**: 아이폰·안드로이드 같은 번호 `v1.2.0`, 설치 파일 이름에 버전을 붙인다 ([app-versions.md](../app-versions.md))

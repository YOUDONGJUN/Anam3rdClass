# 3교시 수정 범위, 예전 화면이 남던 문제

- 날짜: 2026-11-24
- 상태: 완료
- PR: #5

## 배경 (어떤 문제였나)
- 3교시를 연 뒤 시간·인원·대상을 바꿀 수 없었다
- 배포해도 브라우저에 예전 화면이 남았다 (빌드마다 index.html 시각이 같아서 늘 304)

## 정한 것
- 인원: 참여한 사람보다 최대를 줄일 수 없고, 성사 뒤에는 최소를 지금 인원보다 못 올린다
- 대상: 이미 참여한 원우가 빠지게 좁힐 수 없다
- index.html 은 `no-store`, 열어 둔 탭은 앱으로 돌아올 때 새 버전이면 새로고침

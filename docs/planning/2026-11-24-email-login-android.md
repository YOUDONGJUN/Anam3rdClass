# 이메일 로그인, 안드로이드 앱 준비

- 날짜: 2026-11-24
- 상태: 완료
- PR: #6

## 정한 것
- 학교 이메일 + 비밀번호 로그인 (카카오 없이도). 비밀번호를 바꾸면 다른 기기는 로그아웃
- 안드로이드 앱(Capacitor): 카카오톡 로그인, 푸시 알림과 종류별 끄기, 공유, 앱 링크
- 공지: 교수는 자기 학교, 대학원장은 연합 또는 학교 하나. 원우는 못 쓴다

## 버린 대안과 이유
- 원우도 공지 쓰기: 새 공지는 학교 전체에 알림이 가서, 남용을 막으려고 교수·대학원장만 (코드 주석 기준)

# 앱 버전

아이폰·안드로이드 앱은 같은 버전 번호를 써요. 형식은 `v주.부.수` (예: `v1.2.0`).

- **부** (가운데): 새 기능 · **수** (끝): 고친 것
- 설치 파일(.ipa · .apk)을 새로 만들 때마다 올려요. 웹만 바꾼 것은 앱을 다시 깔지 않아도 반영돼요.

## 어디서 바꾸나

| 앱 | 파일 | 버전 | 빌드 번호 (1씩 올림) |
|---|---|---|---|
| 아이폰 | `frontend/ios/App/App.xcodeproj/project.pbxproj` | `MARKETING_VERSION` | `CURRENT_PROJECT_VERSION` |
| 안드로이드 | `frontend/android/app/build.gradle` | `versionName` | `versionCode` |

## 설치 파일 이름

- 아이폰: `anam3-ios-v1.2.0.ipa` — GitHub Actions(iOS 앱)가 버전을 읽어 이름을 붙여요 ([ios-sideload.md](ios-sideload.md))
- 안드로이드: `anam3-android-v1.2.0.apk`
- 받은 파일은 `ipa/` · `apk/` 폴더를 나눠 버전 이름 그대로 보관해요.

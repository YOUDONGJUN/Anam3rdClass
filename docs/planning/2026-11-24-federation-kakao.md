# IT연합회 다섯 학교, 카카오 로그인

- 날짜: 2026-11-24
- 상태: 완료
- PR: #2

## 배경 (어떤 문제였나)
고려대 한 곳에서 IT연합회 다섯 학교(고려대·연세대·성균관대·서강대·한양대)로 넓힌다. 입장 코드 + 아이디·비밀번호로는 학교를 확인할 수 없었다.

## 정한 것
- 카카오 로그인 + 가입할 때 한 번 학교 이메일 인증
- 직책: 대학원장(최고 관리자, 1명) · 교수(대학원장이 임명, 자기 학교만) · 원우
- 우리 학교 / 연합 게시판. 3교시 대상: 우리 학교 · 우리 기수만 · 연합
- 학교 색 테마, 이름 옆 학교 배지
- 신고·차단·탈퇴, 약관 동의, 심한 욕설 거르기

## 버린 대안과 이유
- 입장 코드 + 아이디·비밀번호: 학교를 확인할 수 없어서 버림. 예전 회원은 "예전 계정 잇기"로 기록을 그대로 이어 준다

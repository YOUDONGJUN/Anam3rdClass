# 시간이 겹치는 3교시 막기

- 날짜: 2026-11-26
- 상태: 완료
- PR: #15

## 배경 (어떤 문제였나)

같은 사람이 같은 날, 같은 시각에도 3교시를 여럿 열거나 참여할 수 있었다.

- 같은 시간대 3교시 두 곳에 참여하면 한쪽 자리는 비게 된다(노쇼). 정원이 있는 3교시라면 다른 원우가 탈 자리를 막는다.
- 출석 랭킹도 실제보다 부풀려진다.

## 정한 것

- 내가 열었거나 참여한 3교시끼리는 모임 시간이 **2시간 이상** 떨어져 있어야 한다.
  - 19시 1차 · 21시 2차처럼 나눠 여는 것은 된다. 딱 2시간 차이도 된다.
  - 취소되거나 무산된 3교시는 세지 않는다. 지난 3교시(완료)는 시간으로만 보므로 센다.
- 막는 곳
  - 3교시 열기
  - 참여(나도 콜)
  - 빈자리 알림 받기: 자리가 나도 못 탈 3교시는 기다리지 않게
  - 시간 고치기: 연 사람의 다른 3교시와 견준다. 이 3교시 자신은 빼고 본다
  - 무산된 3교시 되살리기: 그사이 연 사람이 잡은 다른 3교시와 견준다
- 서버 응답: `409 TIME_OVERLAP`
  - 메시지: "앞뒤 2시간 안에 이미 참여한 3교시가 있어요: '치맥 번개' 3/2(월) 21:00"
- 화면
  - 3교시 열기: 시간을 고르는 순간 바로 아래에 알린다. 저장하면 그 칸으로 데려간다.
  - 상세: 참여 버튼 위에 까닭과 겹치는 3교시 링크를 두고, 버튼을 막는다. 누른 뒤에야 알게 되지 않게.
  - 안내는 두 줄로 나눈다. 1줄은 까닭, 2줄은 '제목' · 때. 제목 가운데서 줄이 바뀌지 않는다.
- 설정 `app.meetup.overlap-check` (기본 켜짐)
  - 다른 테스트는 같은 사람이 같은 시각에 3교시를 여럿 열어서 테스트 설정에서는 끈다.
  - 겹침은 `MeetupOverlapApiTest`가 켜고 확인한다.

## 버린 대안과 이유

| 대안 | 버린 이유 |
|---|---|
| 그대로 두기 | 같은 시각 두 곳 참여로 노쇼·자리 막기·랭킹 부풀리기가 생긴다 |
| 하루에 1개만 | 1차·2차를 따로 여는 흔한 경우까지 막힌다 |
| 겹쳐도 경고만 하고 허용 | 노쇼·자리 막기를 그대로 둔다 |
| 모임 끝나는 시간을 받아서 겹침 계산 | 번개 모임이라 끝나는 시간을 정하지 않는다. 입력이 늘어난다 |

## 결과

#15 로 머지. 열기·참여·빈자리 알림·시간 고치기·무산 되살리기에서 앞뒤 2시간 겹침을 막는다.

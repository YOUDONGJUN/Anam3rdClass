# 학교별 화면 이름 (안암 · 신촌 · 서강 · 혜화 · 왕십리3교시)

- 날짜: 2026-11-27
- 상태: 개발 중
- PR: —

## 배경 (어떤 문제였나)

다섯 학교가 함께 쓰는데 이름이 "안암3교시"(고려대 앞 안암역)라서, 다른 학교 원우에게는 남의 학교 서비스처럼 보였다.

## 정한 것

- **공식 서비스 이름은 안암3교시**, 회사는 **써클**. 공식 이름은 나중에 바뀔 수 있어서 화면 코드에서는 한 곳(`lib/credit.ts` SERVICE)만 고치면 되게 한다.
- 로그인하면 **우리 학교 동네 + 3교시**로 보인다. 학교 앞 역·동네 이름으로 통일했다.

| 학교 | 화면 이름 |
|---|---|
| 고려대 | 안암3교시 (공식 이름 그대로) |
| 연세대 | 신촌3교시 |
| 서강대 | 서강3교시 |
| 성균관대 | 혜화3교시 |
| 한양대 | 왕십리3교시 |

- 동네 이름은 학교마다 DB 에 두고(`schools.place`), 대학원장이 관리 › 학교에서 고친다. 연합에 새 학교가 들어오면 이름만 넣으면 된다. 비우면 공식 이름으로 보인다.
- 학교 이름을 고칠 때 동네 이름을 보내지 않으면(예전 화면) 그대로 두고, 빈칸이면 지운다.
- **바뀌는 곳**: 머리 로고, 브라우저 탭 제목, "○○3교시 · by 써클", 써클 창, 공유 문구·캘린더 일정의 `[신촌3교시]`
- **공식 이름 그대로**: 로그인 전 첫 화면, 링크 미리보기, 앱 이름·스토어, 약관·개인정보 처리방침, 인증 메일 — 로그인 전에는 학교를 모르고, 스토어·법적 문서는 이름이 하나여야 한다.
- 색은 지금처럼 **학교 색 테마**(로그인하면 우리 학교 상징색)를 함께 쓴다.

## 버린 대안과 이유

| 대안 | 버린 이유 |
|---|---|
| 공식 이름까지 학교마다 | 스토어·약관·링크 미리보기는 이름이 하나여야 한다 |
| 이름을 화면 코드에 학교 코드별로 적기 | 새 학교가 들어올 때마다 배포해야 한다 |
| 성균관대 "명륜3교시" | 혜화역이 더 잘 알려져 있고, 다른 학교와 같이 역 이름으로 맞춘다 |

# 대학원장 편의: 학교별 시험 계정, 써클 정보, 학교별 랭킹, 원우 편집

- 날짜: 2026-11-26
- 상태: 완료
- PR: #24

## 배경 (어떤 문제였나)

1. 다섯 학교 화면이 어떻게 보이는지 대학원장이 확인할 방법이 없었다. 다른 학교 메일이 없어 가입할 수 없다.
2. "써클"은 글자뿐이라 누가 만들었는지, 어디로 연락하는지 알 수 없었다.
3. 랭킹의 "우리 학교"는 대학원장에게도 고려대만 보였다.
4. 관리 › 원우 표에서 **이름 글자**를 눌러야 관리 창이 열려서 알아채기 어려웠다.

## 정한 것

### 학교별 시험 계정
- Render 환경변수 `SCHOOL_TEST_PASSWORD`(8자 이상)를 넣으면 서버가 시작할 때 학교마다 하나씩 만든다.
  - `ku@test.anam3` · `yonsei@test.anam3` · `skku@test.anam3` · `sogang@test.anam3` · `hanyang@test.anam3`
  - 이름 "고려대 시험계정"처럼, 그 학교 최신 기수 · 첫 학과, 일반 원우, **랭킹에 안 나오기**.
- 로그인 화면의 이메일 로그인으로 들어간다. 비밀번호를 바꾸면 다음 시작 때 바뀐다.
- 다 쓰면 값을 지우고 관리 화면에서 강제 탈퇴시킨다 (스토어 심사 계정과 같은 방식).

### 써클 정보
- "써클" 글자를 누르면 만든 곳 창: 만든 사람 이름 · 학교(대학원) · 기수 · 학과 · 이메일 · 문의 이메일.
- 서버의 **대학원장 계정**에서 읽는다 (`/api/about`). 코드에 개인정보를 적지 않으려고.
- 이메일은 로그인한 원우에게만. 로그인 전 첫 화면에서는 이름과 소속만 보인다 (이메일이 긁히지 않게).

### 학교별 랭킹 (대학원장만)
- 랭킹 › **학교별** 탭에서 다섯 학교 중 하나를 골라 그 학교 원우끼리의 랭킹을 본다 (`?school=`).
- 다른 학교를 볼 때는 대학원장 본인의 "내 기록"을 섞지 않는다.
- 다른 사람이 `school` 을 넣어도 서버가 무시하고 우리 학교를 보여 준다.

### 원우 편집
- 원우 표의 **줄 어디를 눌러도** 관리 창이 열린다. 끝에 [편집] 버튼을 따로 둔다 (키보드 · 알아보기 쉽게).
- 모바일 카드에도 "편집 ›" 표시.

## 버린 대안과 이유

| 대안 | 버린 이유 |
|---|---|
| 시험 계정 비밀번호를 코드에 | 공개 저장소다. 환경변수로만 받는다 |
| 대학원장이 아무 원우로 "대신 들어가기" | 남의 계정으로 들어가는 기능은 사고가 나기 쉽다 |
| 써클 정보를 화면 코드에 고정 | 공개 저장소에 이메일이 남는다. 대학원장이 바뀌면 같이 바뀌어야 한다 |
| 학교별 랭킹을 교수에게도 | 교수는 자기 학교만 관리한다. 우리 학교 탭으로 충분하다 |

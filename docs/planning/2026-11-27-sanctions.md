# 경고 · 정지 (제재 단계)

- 날짜: 2026-11-27
- 상태: 완료
- PR: #27

## 배경 (어떤 문제였나)

신고가 들어오면 교수·대학원장에게 알림이 가고 "이용 차단"(영구)으로 막을 수는 있었지만, 그 사이 단계가 없었다. 가벼운 위반에 바로 영구 정지는 지나치고, 그냥 두면 되풀이된다. 신고당한 횟수나 이전 조치도 보이지 않았다.

## 정한 것

- **경고가 쌓이면 단계가 올라간다**: 1번째 경고 → 2번째 7일 정지 → 3번째 30일 정지 → 4번째 영구 정지. 단계는 서버가 정한다(취소하지 않은 경고 수).
- **신고만으로는 제재하지 않는다**: 허위 신고로 남을 막지 못하게 교수·대학원장이 확인하고 준다. 대신 최근 30일 동안 **서로 다른 원우 3명**이 같은 사람을 신고하면 신고 목록에 "주의 · 원우 3명 신고"를 붙이고, 3번째 신고 때 "주의 신고" 알림을 보낸다.
- 누가 주나: 교수는 자기 학교 원우, 대학원장은 교수까지(이용 정지와 같다). 대학원장에게는 줄 수 없다.
- 어디서 주나: 관리 › 신고(그 신고를 보고 주면 신고도 처리 완료), 관리 › 원우 창. 창에 "이번이 몇 번째 → 무엇이 되는지"를 보여 준다.
- **정지되면**: 바로 로그아웃되고 기간 동안 로그인할 수 없다("이용이 정지된 계정이에요. 12/4(금) 11:00부터 다시 쓸 수 있어요"). 연 모이기 전 3교시는 취소, 참여 중인 3교시에서는 빠진다(영구 정지·탈퇴와 같다). 기간이 끝나면 저절로 풀린다(`members.suspended_until`).
- **경고 받은 원우**: 알림 + 앱을 열면 경고 창(이유 · 운영진이 쓴 내용 · 단계 막대 · "한 번 더 받으면 ○○"). "확인했어요"를 눌러야 닫힌다. 기간 정지는 끝난 뒤 처음 열 때 보인다.
- **잘못 준 경고는 취소**: 원우 창의 기록에서 취소하면 단계에서 빠지고 그 경고로 걸린 정지가 풀린다. "정지 풀기"는 지금 정지만 풀고 기록은 남긴다.
- 기록: `member_sanctions`(V24). 관리 화면 "영구 정지"(바로 차단)도 한 줄로 남는다. 관리자 조치 기록에 "경고"·"경고 취소".
- **강제 탈퇴 대신 영구 정지**: 탈퇴는 이름·이메일을 지워 같은 학교 이메일로 다시 가입할 수 있다. 영구 정지는 계정이 남아 다시 가입할 수 없다.
- 약관 4번(신고·차단·이용 제한)에 단계를 적고 **약관 버전을 2로** 올렸다 → 모든 원우가 다음 접속 때 다시 동의한다. 개인정보 처리방침에 "경고·정지 기록".

## 버린 대안과 이유

| 대안 | 버린 이유 |
|---|---|
| 신고 N건이면 자동 정지 | 여럿이 짜고 허위 신고하면 막을 수 없다 |
| 경고 누적이면 강제 탈퇴 | 탈퇴하면 개인정보가 지워져 같은 이메일로 다시 가입할 수 있다 |
| 경고를 일정 기간 뒤 없애기 | 대학원 과정(2년)이 짧아 지금은 쌓인 그대로 둔다. 필요하면 취소로 뺀다 |
| 단계를 관리자가 매번 고르기 | 사람마다 기준이 달라진다. 단계는 서버가 정하고, 심한 경우만 "영구 정지"를 바로 누른다 |
